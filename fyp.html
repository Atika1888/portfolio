AI-PC Builder 🤖

Intelligent conversational AI system with real-time information retrieval and multi-modal capabilities.

Overview

An advanced AI-powered WhatsApp chatbot that leverages Google Gemini and LangChain to provide intelligent conversations with real-time web search, YouTube video retrieval, and image analysis capabilities. The system seamlessly integrates multiple data sources through APIs to deliver accurate, contextual responses to user queries.

Key Features

  • Real-time web search integration using Tavily Search API
  • YouTube video retrieval and summarization
  • News aggregation through GNews API
  • Image recognition and analysis with ImgBB
  • Voice-to-text conversion using Web Speech API
  • Google Gemini AI (gemini-2.0-flash) for intelligent responses
  • Context-aware conversation with memory management
  • Multi-user support with Firebase Authentication
  • Headless WhatsApp integration
  • Responsive real-time chat interface

Frontend Stack

React.js with TypeScript for type-safe component development • Vite for optimized build and rapid development • Tailwind CSS for modern, responsive UI design • Web Speech API for voice input/output capabilities

Backend Stack

Python 3 with FastAPI for high-performance API endpoints • Node.js for standalone microservices • whatsapp-web.js with headless Puppeteer for WhatsApp integration

AI & Intelligence

Google Gemini API (gemini-2.0-flash model) for natural language understanding • LangChain for prompt engineering and chain orchestration • LangGraph for complex multi-step reasoning workflows • Text Embedding Model (text-embedding-004) for semantic search

Data & Integrations

Firebase Firestore for real-time user data and conversation history • MongoDB Atlas for scalable document storage • External APIs: Tavily Search, YouTube Data API v3, GNews API, ImgBB • Firebase Authentication for secure user management

Development & Deployment

Version Control: Git & GitHub for collaborative development • Design Tools: Figma for UI mockups • Diagramming: Draw.io & PlantUML for architecture documentation • IDE: Visual Studio Code

Architecture Highlights

  • Modular microservices architecture for scalability
  • Asynchronous request handling for optimal performance
  • Real-time data synchronization across platforms
  • Robust error handling and fallback mechanisms
  • Secure API authentication and data encryption
  • Optimized context management for multi-turn conversations
